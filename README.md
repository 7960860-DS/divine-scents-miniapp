# Divine Scents — Telegram Mini App

Каталог магазина внутри Telegram: поиск, бренды, карточка аромата, корзина и оформление заказа.
Открывается кнопкой «Открыть каталог» под полем ввода в боте @DS_opencl_bot или кнопкой «Каталог» в меню бота.

Стек: Nuxt 4 + Vue 3, статичное SPA (сервер не нужен). Каталог — `public/catalog.json`, тот же файл, что у бота и сайта.

## Как устроено

| Что | Где |
|---|---|
| Каталог и поиск (та же логика, что в боте: русские названия, опечатки, «тестер», «мужской») | `app/pages/index.vue`, `app/utils/catalog.ts` |
| Бренды по алфавиту и популярные | `app/pages/brands.vue` |
| Карточка аромата: концентрации, флаконы и тестеры, количество | `app/pages/p/[id].vue` |
| Корзина и форма доставки СДЭК | `app/pages/cart.vue`, `app/utils/order.ts` |
| Связь с Telegram: тема, главная кнопка, «Назад», вибрация | `app/composables/useTelegram.ts`, `useMainButton.ts` |
| Автопубликация на GitHub Pages | `.github/workflows/deploy.yml` |

**Как уходит заказ**

- Mini App открыт кнопкой «Открыть каталог» под полем ввода → заказ отправляется боту (`Telegram.WebApp.sendData`),
  бот пересчитывает цены по своему каталогу и присылает заявку менеджеру. Покупатель получает подтверждение в чате.
- Mini App открыт из меню бота или по ссылке → открывается чат менеджера с готовым текстом заказа,
  покупателю остаётся нажать «Отправить». (Так устроен Telegram: отправлять данные боту может только Mini App,
  открытый с кнопки клавиатуры.)

Корзина и данные формы сохраняются на устройстве покупателя.

## Публикация на GitHub Pages (бесплатно)

1. Зарегистрируйтесь на github.com (если ещё нет аккаунта).
2. Создайте репозиторий: «+» → **New repository** → имя `divine-scents-miniapp` → **Public** → **Create repository**.
3. Загрузите файлы: на странице репозитория **uploading an existing file** → перетащите **всё содержимое** папки
   `divine-scents-miniapp` (папки `app`, `public`, `.github` и файлы `package.json`, `nuxt.config.ts` …) → **Commit changes**.
   Если папка `.github` не загрузилась: **Add file → Create new file**, имя `.github/workflows/deploy.yml`,
   вставьте содержимое этого файла из архива → **Commit changes**.
4. **Settings → Pages → Build and deployment → Source: GitHub Actions**.
5. Вкладка **Actions**: дождитесь зелёной галочки у «Deploy Mini App» (2–4 минуты).
   Адрес приложения: `https://ВАШ-ЛОГИН.github.io/divine-scents-miniapp/`.
6. Откройте адрес в браузере телефона — должен появиться каталог. Вне Telegram вместо кнопки Telegram внизу
   показывается своя кнопка, это нормально.

## Подключение к боту

1. В папке бота замените `bot.py` и `catalog.py` новыми версиями.
2. В `settings.txt` впишите адрес приложения: `WEBAPP_URL=https://ВАШ-ЛОГИН.github.io/divine-scents-miniapp/`.
3. Перезапустите бота (`start.bat`). В окне появится строка «Mini App: https://…».
4. В Telegram отправьте боту `/start` — под полем ввода появится кнопка «Открыть каталог», в меню — «Каталог».

Настраивать что-либо в @BotFather не нужно: бот сам ставит кнопки при запуске.
По желанию в @BotFather → ваш бот → **Bot Settings → Configure Mini App** можно указать тот же адрес —
тогда в профиле бота появится кнопка «Открыть».

## Обновление каталога

Замените `public/catalog.json` в репозитории (**Add file → Upload files**) — сайт пересоберётся сам.
Тот же файл положите в папку бота и перезапустите его.

## Для разработчика

```
npm install
npm run dev        # http://localhost:3000 — проверка в браузере
npm run generate   # статичная сборка в .output/public
```

При сборке под подпапку задайте `NUXT_APP_BASE_URL=/divine-scents-miniapp/`.
Контакты менеджера — в `nuxt.config.ts` (`runtimeConfig.public`) или переменными `NUXT_PUBLIC_MANAGER_TG` и т.д.

Если github.io у части покупателей открывается плохо, приложение можно положить на любой хостинг с HTTPS
(например, на тот же сервер, что и бот, под своим доменом): нужна только папка `.output/public`.
